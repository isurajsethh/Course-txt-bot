## Render Setup
1. Is ZIP ko extract karke apni GitHub repository mein push karein.
2. Render par Web Service (`Docker` ya `Python 3`) create karein.
3. Environment Variables set karein:
   * `BOT_TOKEN` = Aapka Telegram Bot Token
   * `ADMIN_IDS` = Aapka Telegram User ID (optional)
   * `DEFAULT_CREDIT` = `✦ Extracted By: 𝐌𝐫. 𝐒𝐚𝐧𝐬𝐤𝐚𝐫𝐢 ✦`
4. Deploy hone ke baad Telegram mein `/start` bhej kar use karein.
